# Приложение Windows

Albion Craft Lab работает в отдельном окне. Устанавливать браузер, Node.js или Python для использования программы не нужно. Все рецепты и расчёты входят в установщик. Интернет нужен для рыночных цен, изображений предметов и обновления программы.

## Установка и обновление

Скачайте `Albion-Craft-Lab-Setup-1.0.1-x64.exe` из [релизов GitHub](https://github.com/sashasychev05-sketch/albion-craft-lab/releases/latest), запустите установщик и выберите папку. Программа появится в меню «Пуск» и на рабочем столе. Требуется 64-разрядная Windows 10 или 11.

В верхней части окна есть отдельная кнопка «Проверить обновления». Если вышла новая версия, нажмите «Скачать обновление», дождитесь окончания загрузки, затем «Обновить и перезапустить». Новая версия устанавливается поверх старой; мастерства, ручные цены и остальные настройки сохраняются. Обновления не загружаются и не устанавливаются без нажатия кнопки. При ошибке сети можно повторить проверку и продолжать пользоваться текущей версией.

Программа хранит настройки в собственном профиле `%APPDATA%/Albion Craft Lab`. Настройки браузерной версии автоматически не переносятся. При удалении программы профиль сохраняется.

Установщик пока не имеет сертификата цифровой подписи Windows; при первом запуске Windows может показать предупреждение о неизвестном издателе. Скачивайте файл из указанного репозитория. Загруженные обновления проверяются по SHA-512 из метаданных GitHub Releases.

## Разработка

`npm ci` устанавливает зависимости; `npm start` открывает приложение; `npm test` проверяет расчёты и механизм обновлений; `npm run build:win` собирает установщик, `latest.yml` и `.blockmap` в `release/`.

Основное приложение загружает только встроенные файлы через `albion://app/index.html`. Интерфейс работает с изоляцией контекста, песочницей и отключённым доступом к Node.js. Доступ к обновлениям предоставлен тремя ограниченными методами; отправитель сообщений проверяется. Кнопка обновления не связана с кнопкой рыночных цен.

Для следующих релизов увеличьте `version` в `package.json`, обновите lock-файл и отправьте тег `v<version>`. GitHub Actions проверит проект, соберёт Windows x64 и загрузит три файла релиза. Не удаляйте `latest.yml` и `.blockmap`: они нужны механизму обновления. Идентификатор `com.albioncraftlab.desktop`, имя продукта и источник обновлений должны оставаться постоянными.

Основа механизма обновлений: [официальная документация electron-builder](https://www.electron.build/docs/features/auto-update/). Изоляция интерфейса: [рекомендации Electron](https://www.electronjs.org/docs/latest/tutorial/security).
