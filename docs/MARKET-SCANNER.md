# Локальный сканер рынка

Нажмите «Сканер рынка» в верхней части приложения, выберите сервер игры, затем включите встроенный сканер. Для Windows нужен установленный Npcap. Движок поставляется вместе с Albion Lab и работает без собственного окна, трея и автообновления. Закройте отдельно запущенные копии AODP. Просматривайте предложения и заявки в игре: считываются только загруженные страницы.

Клиент запускается с `-i http://127.0.0.1:<случайный порт>/<случайный ключ> -p ""`. Это заменяет адрес публичной выгрузки локальным приёмником. `-d` здесь неприменим: он отключает также локальную HTTP-передачу. Поведение проверено по исходному коду тега AODP 0.1.61. WebSocket не включается.

Ордера сохраняются атомарно в `market-scanner/orders.json` внутри профиля Albion Lab. Срок актуальности — 2 часа. Повторно полученный ордер заменяет свою прежнюю запись. Разные серверы разделены. Сервер указывается пользователем перед запуском, поскольку стандартные HTTP-сообщения клиента его не содержат. Город определяется по LocationId; неподдержанные города не попадают в расчёты.

Свежие считанные цены поступают в существующий PriceBook.resolve: предложения используются для закупки и продажи ордером, заявки — для мгновенной продажи. Ручные цены имеют приоритет. Индивидуальные настройки партии также сохраняются. Чтение рынка само по себе не подтверждает объём исторических продаж: проверки ликвидности в расчётах сохраняются.

Проверены обработка сообщений, преобразование серебра, срок актуальности, локальный HTTP-приём, сохранение и повторное открытие, передача цен в resolver, серверы, качество и ручной приоритет. Встроенный движок на базе 0.1.61 запущен в отдельном профиле: подтверждены отсутствие внешнего окна, получение состояния в приложении и запрет внешнего адреса выгрузки. Полный живой сценарий получения ордеров из игры требует открытого рынка и не подтверждён автоматическими тестами.

## Окно поверх игры

При включении сканера автоматически открывается отдельное окно поверх приложений. Его можно открыть повторно кнопкой «Показать окно поверх игры». Закрытие окна не выключает захват. Окно показывает актуальные цены за 2 часа и последние считанные позиции; кнопка «Ещё 100» раскрывает дополнительные строки. Пауза фиксирует список для чтения, счётчики продолжают обновляться. Число новых и обновлённых ордеров считается за текущее включение; повторное чтение существующего ордера относится к обновлениям.
