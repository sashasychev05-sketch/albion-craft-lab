# Локальный сканер рынка

Нажмите «Сканер рынка» в верхней части приложения, выберите сервер игры и официальный `albiondata-client.exe`, затем включите сканер. Для Windows нужен установленный Npcap. Закройте отдельно запущенные копии AODP. Просматривайте предложения и заявки в игре: считываются только загруженные страницы.

Клиент запускается с `-i http://127.0.0.1:<случайный порт>/<случайный ключ> -p ""`. Это заменяет адрес публичной выгрузки локальным приёмником. `-d` здесь неприменим: он отключает также локальную HTTP-передачу. Поведение проверено по исходному коду тега AODP 0.1.61. WebSocket не включается.

Ордера сохраняются атомарно в `market-scanner/orders.json` внутри профиля Albion Lab. Срок актуальности — 2 часа. Повторно полученный ордер заменяет свою прежнюю запись. Разные серверы разделены. Сервер указывается пользователем перед запуском, поскольку стандартные HTTP-сообщения клиента его не содержат. Город определяется по LocationId; неподдержанные города не попадают в расчёты.

Свежие считанные цены поступают в существующий PriceBook.resolve: предложения используются для закупки и продажи ордером, заявки — для мгновенной продажи. Ручные цены имеют приоритет. Индивидуальные настройки партии также сохраняются. Чтение рынка само по себе не подтверждает объём исторических продаж: проверки ликвидности в расчётах сохраняются.

Проверены обработка сообщений, преобразование серебра, срок актуальности, локальный HTTP-приём, сохранение и повторное открытие, передача цен в resolver, серверы, качество и ручной приоритет. Официальный клиент 0.1.61 запущен в отдельном профиле с локальной маршрутизацией. Полный живой сценарий получения ордеров из игры требует открытого рынка и не подтверждён автоматическими тестами.
