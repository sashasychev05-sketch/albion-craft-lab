Никогда не коммитить оригинальные модели, бинарные модули, карты, настройки группы, игровые снимки и sample-файлы; они не входят в наш установщик.

Несколько физических порталов между одной парой зон пока представлены одной связью.

Тиры T1–T4 синие, T5 красный, T6 оранжевый, T7 жёлтый, T8 белый; выбранный узел сохраняет обводку. Внешние выходы — чёрные/синие/жёлтые/красные квадраты по опасности; внутри тир-качество, например 5-6. Не придумывать качество при null в справочнике.
