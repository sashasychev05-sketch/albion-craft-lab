## Несколько выходов из одной зоны

Проверены 3, 4 и 5 разных направлений. Каждый выход сохраняет собственный таймер; повторное и обратное сканирование не удаляет соседние связи. Проверены путь между двумя соседними зонами через общий узел, неизвестный таймер, запас времени, карточки всех соседей и перезапуск.

На графе с пятью выходами отдельно проверены повторное ручное уточнение, удаление связи без возврата скрытой старой записи и закрытие одного оставшегося портала: остальные ветви сохраняются, истёкший переход скрывается и доступен для просмотра отдельным переключателем. Для 200 разветвлённых графов с циклами результат поиска сравнивался с полным перебором путей.

Исправлены дубликаты ручных таймеров, возврат старой записи после удаления и линии переходов, проходившие через карточки соседних зон. У узлов показано число соединений с другими зонами.
