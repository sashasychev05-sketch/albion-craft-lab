# Albion Lab 1.10.1

- Ручные цены из расчётов сохраняются в «Моих ценах». Сканер рынка добавляет цены закупки и продажи для конкретного города, сервера, предмета и качества. Старые данные не затирают свежую цену.
- Пустые ремесленные журналы отображаются в списке закупок. В новых расчётах журналы включены по умолчанию, отключить их можно там же.
- Сканер порталов берёт стартовую зону из текущего подключения SAT. Для маршрутов доступна кнопка «Моя локация из SAT». Поля назначения отображаются по выбранному типу маршрута.
- Импорт SAT продолжает работу после повреждённой записи. В списке событий появились фильтры боя, предметов и переходов, а также пауза списка.

Для обновления поверх предыдущей версии воспользуйтесь кнопкой «Проверить обновления» или запустите установщик Windows x64.
