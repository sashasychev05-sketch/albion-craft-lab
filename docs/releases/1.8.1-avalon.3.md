# Albion Lab 1.8.1 Avalon.3

- Граф размещает зоны с учётом связей, включая замкнутые маршруты. Зоны можно перетаскивать; кнопка «Перестроить граф» возвращает автоматическое расположение.
- Добавлен поиск круговых маршрутов от выбранной зоны по сохранённым порталам: по золотым или синим плитам, зонам Авалона T8 и указанным ресурсам. Можно задать минимальное количество и максимальное число переходов.
- Для поиска используются порталы с известным временем и заданным запасом. Содержимое зон берётся из справочника: состояние плит и запас ресурсов в игре не считываются. При ограничении сложности приложение сообщает, что список кругов может быть неполным.
- Живой обход в игре ещё не проверен.
