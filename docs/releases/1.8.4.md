# Albion Lab 1.8.4

Сканер рынка встроен в приложение. Для запуска больше не нужно скачивать и выбирать отдельный клиент: нажмите «Сканер рынка», выберите сервер игры и включите сканирование. Управление, состояние захвата и счётчики цен доступны в окне Albion Lab. Движок работает без отдельного окна, значка в трее и собственного автообновления.

Цены передаются только локально, сохраняются на два часа и используются в существующих расчётах. Для захвата трафика Windows требуется Npcap.
