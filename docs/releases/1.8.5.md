# Albion Lab 1.8.5

Включает все изменения после 1.8.2: локальный приём рыночных цен, сохранение ордеров на два часа и подстановку цен в существующие расчёты; встроенный движок AODP без отдельного окна и выбора внешнего клиента. Для захвата в Windows нужен Npcap. Цены считываются при просмотре товаров на рынке игры; ручные цены сохраняют приоритет.

Добавлено окно считанных цен поверх игры. Оно открывается при включении сканера или кнопкой «Показать окно поверх игры». В окне видны количество актуальных цен и ордеров, новые и повторно полученные записи за включение, предметы, качество, город, цены предложений и заявок, время считывания.

Окно перемещается и меняет размер. Список можно приостановить для просмотра; счётчики продолжают обновляться. Кнопка «Ещё 100» раскрывает дополнительные записи. Закрытие окна не выключает сканер.
