# Albion Lab 1.8.7

Оптимизированы сканер рынка и окно считанных цен: запись выполняется асинхронно в последовательной очереди, повторные обходы базы сокращены, частые уведомления интерфейса объединяются. Состояние цен кратковременно кэшируется и сбрасывается после успешного сохранения. Строки окна переиспользуются при обновлении.

Исправлено время подтверждения одинаковых цен. Ошибка записи не заменяет сохранённые данные; последующие пакеты могут быть сохранены повторно. Проверены одновременные пакеты, ошибка диска и восстановление после неё.

При выходе приложение дожидается завершения текущего сохранения цен.
